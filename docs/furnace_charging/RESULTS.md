# Furnace Charging — 결과 (2026-11-23, 서버 x86_64 / RTX A6000)

모든 수치는 이 서버에서 실제로 실행한 시뮬레이션 결과다. 유체는 **Newton 1.8.0 MPM 의 등온 물 수준 유체**(밀도 1000, 점성 0)이며
실제 용탕(밀도·점성·표면장력·열)을 재현하지 않는다. 판 재질은 미확정이고 밀도 후보 2700 kg/m³ 로 계산했다(4.05 kg).
설정값 출처는 `isaac/furnace/config/default.yaml` 과 PLAN §7 (확인값 / 판매처 값 / [가정]).

## 2. 유체 검증 (SPEC §13, `output/furnace/fluid_plate_test/phase1_suite/`)

원통 도가니 내경 0.8 m, 깊이 0.7 m, 액 깊이 0.45 m [가정], 벽 = convex 박스 32 조각 + 바닥 박스. dx 25 mm, 입자 114k.

| # | 항목 | 결과 |
|---|---|---|
| 1 | 액체 유지 | 판 없는 대조에서 탈출 0 %. 벽·바닥 두께 안으로 파고든 입자 최대 0.03 % (수치 관통, splash 와 구분해 집계) |
| 2 | 판·벽 관통 없음 | 통과 (판 최저 z 0.38 m, 최대 반경 0.31 m) |
| 3 | release 후 자유 운동 | 통과 (회전 25°) |
| 4 | 판이 액체를 밀어냄 | 통과 (유체 운동에너지 최대: 판 없음 0.03 J → free_drop 4.4 J, kinematic 24.7 J) |
| 5 | 액체 반력이 판에 반영 | 통과 (진입 후 0.15 s 유체 수직 충격량 / 판 무게 = 2.2) |
| 6 | 입자 위치·질량·속도 읽기 | 통과 |
| 7 | reset 후 복구 | 통과 (reset 후 재실행 판 궤적 차 0.3 mm = 같은 입력 새 객체 두 개의 차이 수준) |
| 8 | 해상도·dt sweep | 표: `sweep.csv`. dx 25/18/12.5 mm, fps 100/200 모두 탈출 0. **진입 후 판의 침강은 해상도에 수렴하지 않음** (§5) |

Phase 1 에서 찾아 고친 수치 문제 (모두 결과 해석에 영향):
- Newton 기본 strain basis `P0` 에서 물이 1.5 s 동안 36 % 압축됨 → `pic8` 로 1.6 %.
- dx 를 줄이면 solver 미수렴으로 바닥 관통이 늘어남 → 반복 횟수를 dx 25/18/12.5 mm 에 50/150/400 으로.
- solver 를 재사용하면 reset 이 불완전 (판 궤적 2.4 cm 차이) → reset 마다 새로 생성.
- 초기 격자 배치의 과도응답을 빼기 위해 판 투입 전 0.5 s 안정화.
- Phase 0 의 1.4 % 누수는 ground plane 과 벽 박스 이음새 문제였고 원통 박스 링 구조에서 사라짐.

## 3. 로봇·그리퍼 (Phase 4, `output/furnace/robot_charge_demo/`)

- M1013 (공식 URDF 변환) + Mobile Base(임시 모델) + 핀 그리퍼(jaw 2 + 핀 50 prismatic 스프링) 를 한 articulation 으로 구성. 랙에 세워진 판의 긴 변을 두께 방향으로 끼워 잡고 용해로 위로 이송.
- 마찰 파지 결과 (핀 스프링 강성은 미정 → 바꿔가며):

| 핀 k [N/m] | 결과 |
|---|---|
| 300 | 들지 못함 (jaw 당 법선력 ≈18 N, 필요 ≈66 N) |
| 1500 | 1.5 cm 들렸다가 미끄러져 놓침 |
| 3000 | 들었으나 이송 중 미끄러져(15 → 10 행 접촉) 도가니로 낙하 |
| 5000 | 랙 → 용해로 위 이송 성공. 이송 중 판-그리퍼 상대 이동 2.7 mm (대부분 가장자리 방향) |

- 도달성: 판을 세운 채 도가니 위에 두려면 판 중심이 도가니 중심에서 로봇 쪽으로 0.25 m 이상, 판 하단 rim 위 ≈0.15 m 이하여야 IK 해가 있다 (작업반경 1.3 m).
- payload: 밀도 후보 7140·7870 이면 판+그리퍼(1.2 kg [가정]) 가 11.9·13.0 kg 로 가반하중 10 kg 초과 → `ROBOT_INFEASIBLE(payload)` 플래그 (`output/furnace/payload_check.json`).

## 4. 파지 추정 (Phase 5) 과 release 비교 (Phase 6)

### 4.1 관측 가능성 (`output/furnace/grasp_estimator/estimator_eval.json`)
핀 변위 야코비안 rank 3: dx(판 중심면 치우침), ry, rz(판 법선 기울기). dz(삽입 깊이)는 12 mm 피치로 양자화.
**dy(가장자리 따라 미끄러짐)와 rx(가장자리 각도)는 관측 불가** → 사전값 0. dy 는 카메라 등 별도 센서가 필요하다.
합성 500 건 RMSE (보정 안 할 때): dx 0.36 mm (1.19), ry 0.13° (1.76), rz 0.06° (1.72), dz 3.4 mm (4.7), dy 11.3 mm (11.3, 변화 없음).
Phase 4 물리 로그: dx 추정 0.47 mm vs GT 0.50 mm, 판 두께 9.92 mm vs 10 mm.

### 4.2 조건 비교 (`output/furnace/evaluate/phase6/`, seed 0–19, 같은 seed = 같은 파지 오차)
파지 오차 [가정]: dx ±2 mm, dy ±20 mm, dz ±8 mm, rx·ry·rz ±3° (균일). 목표 = 판을 세워(가장자리부터) 판 하단이 액면 위 0.15 m, 판 중심 = 도가니 중심에서 로봇 쪽 0.25 m. D = A 와 같고 높이만 0.06 m.

| 지표 (평균 ± 표준편차, n=20) | A 고정 | B 핀 추정 보정 | C oracle | D 낮게 |
|---|---|---|---|---|
| release 위치 오차 [mm] | 11.6 ± 6.2 | 9.9 ± 6.3 | 0 | 11.6 ± 6.2 |
| release 각도 오차 [°] | 2.81 ± 0.94 | 1.65 ± 0.84 | 0 | 2.81 ± 0.94 |
| 용기 밖 탈출 질량 − 기준선 [kg] | 0 | 0 | 0 | 0 |
| rim 위 질량 최대 [kg] | 0 | 0 | 0 | 0 |
| 비산 높이 p99.9 [m] | 0.0121 ± 0.0013 | 0.0122 ± 0.0007 | 0.0140 ± 0.0002 | 0.0093 ± 0.0032 |
| 유체 운동에너지 최대 [J] | 2.10 ± 0.28 | 1.82 ± 0.18 | 2.18 ± 0.05 | 1.31 ± 0.34 |
| 진입 중 벽 접촉 | 0/20 | 0/20 | 0/20 | 0/20 |
| 그리퍼에 유체 닿음 | 0/20 | 0/20 | 0/20 | 0/20 |
| 로봇 도달 가능 | 20/20 | 20/20 | 20/20 | 20/20 |

같은 입력 3 회 반복의 잡음: 비산 높이 ±0.0002 m, 운동에너지 ±0.01 J (`repeat`).

해석 (이 조건에서만):
- 핀 추정 보정(B)은 release 각도 오차를 2.8° → 1.7° 로 줄였다. 위치 오차는 관측 불가인 dy 가 지배해 11.6 → 9.9 mm 로 조금만 줄었다.
- 이 투입 조건(판을 세워 15 cm 에서 놓기, rim 까지 여유 25 cm)에서는 **어느 조건도 용기 밖 탈출·rim 넘침이 0** 이라 splash 질량으로는 A/B/C 를 구분할 수 없다. 운동에너지·비산 높이 차이는 반복 잡음보다 크지만 자세 오차와 단조 관계가 아니다 (C 가 A 보다 약간 큼) — 판이 정확히 수직으로 들어가는 경우와 조금 기울어 들어가는 경우의 차이로 보이며 "추정 보정이 splash 를 줄였다" 는 근거는 되지 않는다.
- 높이를 0.15 → 0.06 m 로 낮춘 D 는 운동에너지 2.1 → 1.3 J, 비산 높이 12 → 9 mm 로, 이 조건에서는 추정 보정보다 높이를 낮춘 효과가 크다.

### 4.3 높이·기울기 sweep (조건 A, 3 seed, dx 25 mm, `height_pitch_sweep.png`)
- 유체 운동에너지는 높이에 따라 커지고, 수평 판(pitch 90°)이 가장 크다 (0.5 m: 수평 22.9 J, 수직 6.3 J, 45° 5.0 J). 비산 높이 p99.9 도 수평·45° 가 수직보다 크다.
- 모든 sweep 조건에서 탈출·rim 넘침 0 (액면~rim 25 cm [가정]).
- 45° 판은 모든 높이에서 진입 중 도가니 벽에 닿았다 (기운 판이 비스듬히 미끄러짐). 수평 판은 0.15 m 이상에서 1/3 이 닿음.
- 0.5 m 수직은 로봇 IK 해 없음 (도달 불가로 표시, 시뮬레이션은 함).
- 0.05 m · 45° 의 비산 높이 0.054 m 는 저해상도에서 seed 간 편차가 크고(±0.05) 고해상도(dx 12.5 mm)에서는 0.020 m → **저해상도의 작은 높이 결과는 믿기 어렵다**.
- 결론을 미리 정하지 않았고, "기울일수록 splash 감소" 는 이 데이터에서 성립하지 않았다 (수직이 가장 작음).

## 5. 알려진 한계
- 유체: 물 수준 등온 유체. 판(10 mm) 이 격자(12.5–25 mm) 보다 얇아 진입 후 침강이 해상도에 수렴하지 않음 (밀도 2700 판이 1.5 s 에 3–8 cm 만 가라앉음, 단순 종단속도 추정 ≈0.5 m/s). 진입 직후 지표만 비교에 썼다.
- splash 질량 지표가 이 조건 범위에서 모두 0 → 비교 해상도가 부족. 더 높은 투입·더 낮은 freeboard·더 무거운 유체(fluid_dense 설정) 조건이 다음 검증 항목.
- B 조건의 핀 변위는 기하 모델 + 잡음. Phase 4 물리 핀으로 회전 파지 오차를 만든 실험은 하지 않았다.
- jaw 를 여는 동안 판에 주는 교란, release 직전 로봇 속도, 작업 시간(task_time)은 모델링하지 않았다 (CSV 에 None).
- 그리퍼-유체 충돌은 "유체 최고점이 릴리스 위치의 그리퍼 하단 높이에 닿는가" 로만 근사.
- `wall_contact_any_time` 은 가라앉은 뒤 판이 벽 쪽으로 표류한 것도 세므로(경계 3 mm) 비교에 쓰지 않는다. 진입 중 접촉(`entry_wall_contact`)만 쓴다.
- GPU 비결정성: 같은 입력의 판 궤적 차이 ≤0.3 mm, 지표 차이는 위 repeat 수준.
- 핀 스프링 강성 5000 N/m, 그리퍼 질량 1.2 kg, 마찰 0.3/0.5 는 [가정]. 실측이 오면 Phase 4·6 재실행 필요.
- Mobile Base 는 임시 모델, 용해로·공장은 절차적 모델이다. 실제 장비 CAD 아님.
